# Journal des modifications

Toutes les modifications notables effectivement livrées sont consignées ici. Le format suit [Keep a Changelog](https://keepachangelog.com/fr/1.1.0/) et le projet utilise [Semantic Versioning](https://semver.org/lang/fr/).

Les rubriques décrivent ce qui est réellement livré, pas les intentions ou fonctionnalités simplement prévues. Une version publiée ne doit jamais être réécrite ou réutilisée.

### Fixed
